# POO-SmartTecnoHouse

Proyecto de la asignatura **Programación Orientada a Objetos** (1.º de Ingeniería Informática).

Simulación de un sistema domótico inteligente desarrollado en Java, aplicando programación orientada a objetos, patrones de diseño (Strategy y MVC), interfaz gráfica con Swing y persistencia en ficheros.

## Autor
Javier Bejerano Caballero

## Tecnologías
- Java
- Swing (interfaz gráfica)
- Git / GitHub (control de versiones)

## Estructura del proyecto
- **modelo**: sensores, actuadores y reglas del sistema.
- **vista**: interfaz gráfica (Swing).
- **controlador**: gestión de eventos y conexión entre vista y modelo (patrón MVC).
